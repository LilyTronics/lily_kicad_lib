# Toolbox

Various tools for working with KiCad.

Tools run from the tools folder in the tool runner application. They are dynamically loaded.
Changes in a tool are available after reload in the tool runner application.
Only the tool runner application is compiled to an executable (the toolbox application). The tools are run from the Python code.

Tools can be added by copying the template folder and modify to your needs.

The template tool is only available when running the tool runnner from Python code. The comiled executable does not show the template tool.
